== Scope

This document exists to prove that the packed-metanorma v2 stack compiles an
ISO-flavour document to PDF end to end: jing schema validation, the
fontist font pipeline against the host `~/.fontist` cache (fonts from
the public fontist formulas, downloaded at compile time), and
mn2pdf/Apache FOP running on the bundled JRE payload.

== Terms and definitions

=== acceptance test

process that proves a system works end to end under its real runtime
composition

=== payload

a tebako image slice mounted into the runtime at execution time
